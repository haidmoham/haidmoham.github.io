Closed loop, bounded claim

Vertical support is now measured and corrected

A stance-only, support-aware loop reads torso attitude and support state, then makes bounded all-feet target corrections only inside declared six-foot support. It helps C-1N remain vertical; standing is not yet robust.

Checkpoint lineage

The robot should make its own evolution inspectable.

C-1N is the integration point. The Robotics Test Bench isolates the physical questions that make a checkpoint legible. A checkpoint advances only for a demonstrated capability or an understood failure worth preserving and comparing.

  • C-1N // 00 · SPAWN — historical deterministic six-foot spawn baseline. It does not claim standing or walking.
  • C-1N // 01 · SHUFFLE — preserved coordinated-gait failure. Motion is not controlled locomotion.
  • C-1N // 02 · STAND — reproducible six-contact support baseline with a bounded support-aware vertical loop. This is standing evidence, not robust disturbance recovery.
  • C-1N // 03 · ROBUST_STAND — next phase: recover the declared 1 mg shove cases across all eight orientations before advancing toward stride.
Worth noting: The STAND loop is closed, but its operating boundary is explicit: it only corrects while six contacts remain declared. A lost contact or 1 mg shove is not quietly relabeled as success.
